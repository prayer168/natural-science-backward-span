# 教師使用說明

## 活動目的

以短時間的倒序記憶活動，協助學生把注意力帶進自然課。這不是標準化心理測驗，也不應用來推斷智力、學習能力或診斷狀況。

## 課前操作

1. 依當天課程選擇數字、自然圖卡、自然詞語或自訂題組。
2. 自然題型可選年級、出版社與課程單元；題組標明學期和出處。
3. 選擇序列長度及呈現速度。第一次使用可由 6 個項目開始。
4. 按「開始挑戰」。每個項目依序出現後消失，學生從最後一項開始倒序作答。
5. 圖卡／詞語用點選排列；數字以鍵盤輸入。教師可在序列播放時按同一按鈕暫停或繼續。
6. 練習模式答錯可看正確順序並再試；挑戰模式為五回合，不提供答案揭示。

## 課堂建議

- 可投影後全班口頭或紙筆一起參與；開啟「大字投影」切換到較大的遊戲畫面。
- 不必要求所有學生達到相同長度。可把重點放在安靜觀察、等待序列結束及重新嘗試。
- 不公開排名、不保存學生作答、不將結果作為成績。
- 課程地圖跨版本比對不代表出版社共同規定的先修順序，請以班級實際教材為準。

## 目前題庫主題

三年級：植物構造、動物構造與生存、天氣觀測。

四年級：水生生物、昆蟲觀察、日月星辰與月相。

五年級：地層、岩石、礦物、土壤與大地變動。

六年級：岩石礦物土壤、生物與環境、生態系。

完整出版社／學期／單元對照請查看 `docs/course-map-grades-3-6.md` 與 `data.js`。可在 `data.js` 依相同欄位新增題組；插畫符號為記憶辨識用示意，並非物種形態圖鑑。
