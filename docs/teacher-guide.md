# 教師使用說明

## 活動目的

以短時間的倒序記憶活動，協助學生把注意力帶進自然課。這不是標準化心理測驗，也不應用來推斷智力、學習能力或診斷狀況。

## 課前操作

1. 依當天課程選擇數字、自然圖卡、自然詞語或自訂題組。
2. 自然題型可選三至六年級、康軒／翰林／南一版本與課程單元；每題會標示年級、學期、版本和來源單元。
3. 數字模式可設定 6–12 位；自然題型依該單元課程地圖中的活動數自動設定長度（2–4 項）；自訂題組可輸入 3–12 個詞語。
4. 選擇呈現速度和練習／挑戰模式，再按「開始挑戰」。每個項目依序出現後消失，學生從最後一項開始倒序作答。
5. 圖卡／詞語以觸控或滑鼠點選排列；數字以鍵盤輸入。教師可在序列播放時暫停或繼續。
6. 練習模式答錯會顯示倒序供參考；挑戰模式為五回合，不提供答案揭示。

## 課堂建議

- 投影可使用「大字投影」放大遊戲區，也可按「全螢幕」讓瀏覽器填滿投影畫面；按 Esc 可退出瀏覽器全螢幕。
- 手機和平板會依螢幕寬度調整欄位與按鈕；建議使用橫向投影或直向個人操作皆可。
- 不必要求所有學生達到相同長度。可把重點放在安靜觀察、等待序列結束及重新嘗試。
- 不公開排名、不保存學生作答、不將結果作為成績。
- 課程地圖跨版本比對不代表出版社共同規定的先修順序，請以班級實際教材為準。

## 題庫範圍

題庫依課程地圖納入三至六年級康軒、翰林、南一三版本的所有單元和教學活動，共 93 組版本／學期／單元與 279 個活動標題。活動名稱依來源呈現，圖卡符號為方便辨識的簡化記憶提示，並非寫實形態圖鑑。
