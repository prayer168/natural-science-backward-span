# 自然倒背挑戰

網站：https://prayer168.github.io/natural-science-backward-span/

## 八種關卡
1. 數字：3～12 個；播放與輸入答案時逐字中文發音，可關閉語音。頁面有觸控數字鍵盤，也支援實體鍵盤。
2. 特殊符號：3～12 個不同符號，隨機出現後倒序點選。
3. 生物圖卡：65 種生物插圖，每題隨機抽 3～12 張，沒有活動名稱或圖片下方文字；圖片使用本機 SVG。
4. 自訂題組：輸入 3～12 個短詞，以逗號或換行分隔。
5. 顏色：六種色塊各有不同形狀，記住出現順序後倒序點選，可重複出現。
6. 方位：選擇四方位（東南西北）或八方位（另加東北、東南、西南、西北）；只倒轉順序，不改變方位。
7. 聲音：狗、貓、青蛙、公雞、牛、綿羊、馬、鴨的真實錄音，取自黑熊老師「聲音實驗室」。播放時只聽聲音，倒序點選對應生物圖片；裝置需開啟音量。頁面「音訊出處」可查看作者與授權。
8. 位置：九宮格依序亮起，倒序點選相同位置。

## 共同設定
- 3～12 個項目；除圖卡、特殊符號與自訂題組外，項目可重複出現。
- 作答限時 10、20、30、40、50、60 秒，播放完成後才開始倒數。
- 練習一題，或挑戰五題。練習模式答錯會顯示正確倒序。
- 刪除一步、清除、重看同題、下一題、重新開始。
- 手機與低高度橫向螢幕播放、作答及結果時收合設定區，可用「重新開始」回到設定。
- 單頁 RWD 與全螢幕按鈕，操作不用跳頁；右下有版權與電子信箱。
- 不蒐集學生資料。瀏覽器／裝置需提供中文語音才能發音。

## 本機使用
直接開啟 index.html，或用靜態 HTTP 伺服器。網站程式不依賴第三方框架。

舊版 docs 內的手冊是歷史版本；現行操作以本 README 與網站為準。

## Playwright
playwright-check.cjs 為驗證程式；需安裝 Playwright 與 Chromium。
設定 TEST_URL 指向本機或線上網址，執行 node playwright-check.cjs。
語音驗證使用測試替身檢查呼叫與發音文字，實際聽音品質須於裝置上確認。Web Audio 也只驗證啟動流程，不代替實際聽音。
