# 自然倒背挑戰

適用國小三至六年級自然課的課前專注暖身互動網站。學生依序記住數字、自然詞語或圖卡，再從最後一項開始倒序回答。活動不記名、不排名，也不作智力或診斷評量。

## 目前功能

- 數字倒背：6–12 位數。
- 自然圖卡、自然詞語倒序，以及教師自訂 3–12 個詞語。
- 依三至六年級、學期、出版社與課程單元篩選已整理的題庫。
- 可調整序列播放速度，選擇練習或五回合挑戰。
- 答錯時練習模式提供正確順序，挑戰模式保留回想機會。
- 觸控／滑鼠點選作答、撤銷、清除重排；鍵盤可操作按鈕與輸入答案。
- 大字投影、音效開關、教師使用說明與螢幕閱讀器播報。
- 響應式版面與降低動態效果支援。

## 本機開啟

直接以瀏覽器開啟 `index.html` 即可使用，無需安裝套件或連接網路。網頁字體會嘗試載入 Google Fonts；離線時使用系統字體。

## GitHub Pages

網站來源位於獨立的 `website/` 資料夾，影片錄製與剪輯資產不在網站目錄內。Repo 英文名預定為 `natural-science-backward-span`。GitHub Pages 部署設定與公開網址將在建立 GitHub Repo 後補上。
